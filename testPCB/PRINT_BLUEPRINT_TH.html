Blueprint — Security Door Lock PCB (door-demo01)

บอร์ดด้านเดียว BottomLayer · 88 × 148 mm · ไฟล์ PCB_demo_last.json

1) ขั้นตอนพิมพ์ลาย (Toner Transfer)

  1. EasyEDA → File → Open → EasyEDA Source เลือกไฟล์ JSON ด้านบน
  2. Design → Check DRC ต้องไม่มี Clearance / Track-to-Pad / Track-to-Track / Short (ผลในไฟล์นี้คำนวณจาก JSON ต้องยืนยัน DRC จริงในโปรแกรม)
  3. แสดงเฉพาะ BottomLayer + Pad + Hole + BoardOutLine ซ่อน TopLayer / Silkscreen / Document
  4. Ctrl+P → Scale 100% (Actual size) ปิด Fit to page, กระดาษ A4 แนวตั้ง
  5. วัด: กรอบ 88×148 mm, pitch ESP32 = 2.54 mm
  6. ตรวจกลับด้าน: อ้างอิง OLED1 (ซ้ายบน) กับ 5V_OUT (ขวาล่าง) — วางหมึกคว่ำบนทองแดงแล้วเช็คซ้าย–ขวา อย่าเดา Mirror

2) จุดต้องระวัง

รู Mounting 2.3 mm (M2) — NPTH ห้ามบัดกรี เจาะแล้วไม่ต่อวงจร
Clearance แก้ครบแล้ว (เดิม 11 จุด H1–H11 ต่ำกว่า 0.45 mm) อย่าย้ายลายกลับไปทับตำแหน่งเดิมรอบ C2 / RFID_IN 7-8 / J2 / ESP32 29-30
OLED ต่อตามป้ายกำกับ (VCC/GND/SCL/SDA) ไม่ใช่ตำแหน่ง — แต่ละร้านเรียงขาไม่เหมือนกัน
ก่อนจ่ายไฟวัด short 5V↔GND และ 3.3V↔GND หลังจัปสายครบทุกเส้น
Echo เข้า GPIO27 ต้องผ่านตัวแบ่ง R1/R4 (1k/2k) ห้ามต่อตรง
GPIO12 = strapping pin ห้ามดึงลง GND ตอน boot (บอร์ดนี้ไม่ได้ใช้ขานี้)

6) ภาพประกอบ (พิมพ์ 1:1)

7) ลำดับบัดกรี–ทดสอบ

  1. บัดกรี R1/R4 → C1–C4 → ขั้วต่อทั้งหมด → ESP32 (หรือหัว Female)
  2. จัป W1–W11 ทีละเส้น ตรวจไม่แตะลายอื่น
  3. วัดไม่ต่อกัน: 5V↔GND, 3.3V↔GND, 3.3V↔5V
  4. จ่าย 5V → วัด 3.3V/5V ถูกต้อง
  5. Serial 115200 → บอร์ดต่อ Wi-Fi → ทาบบัตร → เช็ค GET /access/recent
