# Mainboard-min-handmade — บอร์ด minimal สำหรับ **กัดแผ่นเอง (หน้าเดียว)**

เวอร์ชันเดียวกับ `mainboard-min` (ESP32 DevKit V1 เสียบ, อุปกรณ์หลักอย่างเดียว,
ไฟจากตัวแปลงภายนอก) แต่เดินลาย **หน้าเดียว (F.Cu)** สำหรับทำ toner transfer
กัดกรดเอง + เดินสาย jumper บางเส้นด้วยมือ

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| **`ETCH_copper_mirrored.pdf`** | ⭐ ลายทองแดง (กลับด้านซ้าย-ขวา) สำหรับ **ปริ้นรีดลงแผ่นทองแดง** |
| `copper_normal.pdf` | ลายทองแดงมุมมองปกติ (ไว้ดูเทียบ ไม่ใช่ตัวรีด) |
| **`PLACEMENT_guide.pdf`** | ⭐ ผังวางอุปกรณ์ + ป้าย GPIO (ดูตอนบัดกรี) |
| **`JUMPERS.md`** | ⭐ รายการสาย jumper 14 เส้นที่ต้องเดินด้วยมือ |
| `mainboard.kicad_pro/.kicad_pcb` | เปิดใน KiCad ดู/แก้ได้ |
| `handmade_top.png` | ภาพ preview |

## สรุปสเปกบอร์ด
- **หน้าเดียว** (ทองแดง F.Cu), เส้น 0.5mm / เส้นไฟ 0.6mm, clearance 0.45mm
  (เผื่อไว้ให้กัดเองง่าย)
- GND = **เททองแดงทั้งแผ่น (pour)** ทุกจุด GND เชื่อมผ่านพื้นนี้
- เดินลายทองแดงได้ 20 เส้น + **jumper 14 เส้น** (สายหุ้มฉนวนบัดกรีด้านบน)
- ขนาด 88 × 148 mm, รูยึด M2 4 รู

> ทำไมมี jumper เยอะ: DevKit เสียบวางกลางบอร์ด บัง 2 แถวยาว ทำให้สายต้อง
> ข้ามกันหลายจุด — หน้าเดียวจึงเลี่ยง jumper ไม่ได้ (ถ้าไม่อยากเดิน jumper
> ให้สั่งบอร์ด 2 ชั้นจากโฟลเดอร์ `mainboard-min-routed` แทน)

## ขั้นตอนทำแผ่นเอง (toner transfer)

1. **ปริ้น `ETCH_copper_mirrored.pdf`** ด้วยเลเซอร์ ลงกระดาษกลอสซี/กระดาษลอกลาย
   — ตั้งสเกล **100% (จริงเท่าขนาด)** ห้ามย่อ/ขยาย
2. ตัดแผ่นทองแดงตามขนาด → ขัดผิวให้สะอาด
3. วางกระดาษ**คว่ำหน้าที่มีหมึกลงบนทองแดง** แล้วรีดด้วยเตารีดร้อน ~5-10 นาที
4. แช่น้ำ ลอกกระดาษออก เหลือหมึกเป็นลายบนทองแดง
5. **กัดกรด** (เฟอร์ริกคลอไรด์ / กรดกัดปริ้น) จนทองแดงส่วนที่ไม่มีหมึกหายหมด
6. ล้าง ขัดหมึกออก → เจาะรูตามจุด pad (ดู `PLACEMENT_guide.pdf`)
   - รูขา header/DevKit socket: ดอก ~1.0mm
   - รูยึด M2: ดอก ~2.3mm
   - รู via ของ jumper: ดอก ~0.7mm
7. **บัดกรีอุปกรณ์** (ดู `PLACEMENT_guide.pdf` ว่าตัวไหนอยู่ตรงไหน)
8. **เดินสาย jumper 14 เส้นตาม `JUMPERS.md`** ด้วยสายไฟหุ้มฉนวนด้านบนบอร์ด
   (สายข้ามกันได้เพราะหุ้มฉนวน)

> ⚠️ เรื่องกลับด้าน: ผมให้ไฟล์รีด (`_mirrored`) กลับซ้าย-ขวาไว้แล้ว สำหรับวิธี
> "รีดหมึกคว่ำลงทองแดง" มาตรฐาน ถ้าวิธีของคุณต่างออกไป (เช่นใช้ฟิล์ม dry-film
> หรือพิมพ์ผ่านสื่อใส) ให้ดู `copper_normal.pdf` เทียบว่าต้องกลับด้านไหม

## อุปกรณ์ที่ต้องหามาติด (BOM ย่อ)
| Ref | อุปกรณ์ |
|---|---|
| U1 | ซ็อกเก็ตตัวเมีย 2×15 (1x15 female header ×2) สำหรับเสียบ ESP32 DevKit V1 |
| J1 | ขั้วต่อไฟเข้า 2 ขา (5V, GND) |
| J3, J4 | pin header 1×8 (ไป RC522 ×2) |
| J5 | pin header 1×4 (ไป OLED) |
| J6 | pin header 1×4 (ไป HY-SRF05) |
| J7 | pin header 1×4 (ไป ESP32-CAM) |
| J8 | pin header 1×3 (ไป relay module: VCC/GND/IN) |
| J9 | pin header 1×2 (ไป buzzer) |
| Q1 | ทรานซิสเตอร์ NPN (S8050 / 2N2222) ขับ buzzer |
| R4, R5 | 4.7kΩ (I2C pull-up ของ OLED) |
| R6 | 1kΩ (ตัวแบ่งแรงดัน ECHO ตัวบน) |
| R7 | 2kΩ (ตัวแบ่งแรงดัน ECHO ตัวล่าง) |
| R8 | 1kΩ (จำกัดกระแส base ของ Q1) |
| — | สายไฟหุ้มฉนวนเส้นเล็ก สำหรับ jumper 14 เส้น |

> R4-R8, Q1 เป็น SMD (0805 / SOT-23) ในไฟล์นี้ — ถ้าอยากใช้แบบขาเสียบ (through-hole)
> บอกผมได้ จะเปลี่ยน footprint ให้บัดกรีมือง่ายขึ้น

ซ้าย(บน→ล่าง): EN 36 39 34 35 32 33 25 26 27 14 12 13 GND VIN
ขวา(บน→ล่าง): 3V3 GND 15 2 4 16 17 5 18 19 21 RX0 TX0 22 23
