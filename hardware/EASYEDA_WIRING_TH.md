# คู่มือต่อสาย (EasyEDA) — Security Door Lock

รายการต่อสายสำหรับสکีมาติกใน EasyEDA — **อ้างอิงจากเฟิร์มแวร์จริงที่ใช้:**
`firmware/esp32-main/src/esp_main/full-main_test.ino` (เวอร์ชัน **ESP-NOW**)

> ⚠️ **สำคัญ:** repo มีเฟิร์มแวร์ 2 เวอร์ชัน — `main.cpp` (โมดูลาร์, คุย CAM ทาง UART)
> กับ `full-main_test.ino` (ที่คุณใช้, คุย CAM ทาง **ESP-NOW ไร้สาย**). **pin ของสอง
> เวอร์ชันไม่เหมือนกัน** เอกสารนี้ยึดตาม `.ino` ที่คุณใช้จริง
>
> ➜ **ESP32-CAM ไม่มีสายต่อกับ ESP32 หลัก** — คุยกันผ่านคลื่น WiFi (ESP-NOW)
>   ต้องจ่ายไฟให้ CAM แยก + ตั้ง **MAC address** ให้ตรงในโค้ดเท่านั้น

**อุปกรณ์:** ESP32 DevKit V1 (U3), RC522 ×2 (U1/U2), HC-SR04 (U5), OLED SH1106 (U7),
Relay module (U6), Buzzer (BZ1)+S8050 (Q1), R1,R2=4.7k · R3=2k · R4,R5=1k
**ไฟ:** step-down 12V→5V

---

## 1. ไฟเลี้ยง (12V → step-down → 5V)

```
อะแดปเตอร์ 12V ──┬── step-down IN(12V) ── OUT(5V) ──► ราง 5V
                 │
                 └── 12V ──► Relay COM ── NO ──► โซลินอยด์ (ล็อก 12V)

GND ทุกก้อน (12V, step-down, ทุกโมดูล, ESP32-CAM) ต่อถึงกัน = ราง GND
```

| ราง | มาจาก | จ่ายให้ |
|---|---|---|
| **5V** | step-down OUT | ESP32 **VIN**(ขา15) · HC-SR04 VCC · Relay **+** · Buzzer **+** · **ESP32-CAM 5V** |
| **3.3V** | ESP32 ขา **3V3**(ขา30) | RC522 U1.8 · RC522 U2.8 · OLED Vcc · ปลายบน R1,R2 |
| **GND** | ร่วมทั้งระบบ | ทุกโมดูล + ปลายล่าง R3 + Q1.E + 12V(−) + CAM GND |
| **12V** | อะแดปเตอร์ | step-down IN · Relay COM (ไปโซลินอยด์) |

> ⚠️ step-down ปรับ OUT ให้ **5V** (วัดด้วยมัลติมิเตอร์) และจ่ายได้ ≥1A

## 3. RC522 #2 = U2 (ทางออก / HSPI)

| RC522 U2 | → ESP32 |
|---|---|
| 1 SDA | **TX2** (ขา24 / GPIO17) |
| 2 SCK | **D14** (GPIO14) |
| 3 MOSI | **D13** (GPIO13) |
| 4 MISO | **D35** (GPIO35) |
| 7 RST | **D2** (GPIO2) |
| 8 3.3V | ราง 3.3V |
| 6 GND | ราง GND |
| 5 IRQ | ไม่ต่อ |

> หมายเหตุ: SDA ของหัวออกไปที่ขา **TX2 (GPIO17)** — ในเวอร์ชัน ESP-NOW ขานี้ว่าง
> (ไม่ได้ใช้เป็น UART แล้ว) จึงเอามาใช้เป็น SS ของ RFID ตัวที่ 2

## 4. OLED SH1106 (U7, I2C)

| OLED | → |
|---|---|
| 1 Vcc | ราง 3.3V |
| 2 Gnd | ราง GND |
| 3 SCL | ESP32 **D22** (GPIO22) |
| 4 SDA | ESP32 **D21** (GPIO21) |
| R1 (4.7k) | คร่อม SDA ↔ 3.3V (pull-up) |
| R2 (4.7k) | คร่อม SCL ↔ 3.3V (pull-up) |

## 5. HC-SR04 (U5) — ⚠️ ECHO เป็น 5V ต้องมีตัวแบ่งแรงดัน

| | |
|---|---|
| 1 VCC | ราง 5V |
| 4 GND | ราง GND |
| 2 TRIG | ESP32 **D26** (GPIO26) *(ต่อตรงได้)* |
| 3 ECHO | → **R4(1k)** → จุด A |
| จุด A | → ESP32 **D27** (GPIO27) **และ** → **R3(2k)** → GND |

```
ECHO ──[R4 1k]──┬── D27 (ESP32 GPIO27)
                │
              [R3 2k]
                │
               GND
```
(5V × 2k/(1k+2k) = 3.33V ← ปลอดภัยกับ ESP32)

## 6. Buzzer (BZ1) + Q1 (S8050) + R5

| | |
|---|---|
| ESP32 **D33** (GPIO33) | → **R5(1k)** → Q1.**B**(ขา2) |
| Q1.**C**(ขา3) | → BZ1.**−**(ขา2) |
| Q1.**E**(ขา1) | → ราง GND |
| BZ1.**+**(ขา1) | → ราง 5V |

| U6 | → |
|---|---|
| **S (IN)** | ESP32 **D25** (GPIO25) |
| **+** | ราง 5V |
| **−** | ราง GND |
| **COM** | 12V+ |

## 8. ESP32-CAM — **ไร้สาย (ESP-NOW) ไม่มีสายข้อมูล**

ESP32-CAM คุยกับ ESP32 หลักผ่าน **ESP-NOW** (คลื่น WiFi) — **ไม่ต้องเดินสาย TX/RX**
ต่อแค่ **ไฟเลี้ยง** เท่านั้น (จะจ่ายจาก step-down 5V ก้อนเดียวกัน หรือแยกก็ได้)

| ESP32-CAM | → |
|---|---|
| 5V | ราง 5V |
| GND | ราง GND (ต้องร่วมกับระบบ) |
| (ไม่มีสายข้อมูล) | — คุยไร้สาย |

**สิ่งที่ต้องทำในโค้ดแทนการเดินสาย:**
1. เปิด Serial Monitor ฝั่ง ESP32-CAM อ่านค่า **MAC address**
2. เอา MAC ไปใส่ในตัวแปร `camMacAddress[]` ใน `full-main_test.ino`
3. ตั้ง WiFi SSID/PASS ฝั่ง CAM ให้ตรงเราเตอร์ (สำหรับส่งภาพขึ้นเซิร์ฟเวอร์)

> กล้องกินกระแสตอนส่งภาพได้ถึง ~500mA → ถ้าจ่ายจาก step-down ก้อนเดียว
> เลือกก้อนที่จ่ายได้ ≥1.5A เผื่อทั้งระบบ

## ⚠️ จุดที่ต้องระวัง
1. **ยึดตาม `.ino` (ESP-NOW)** — pin ต่างจาก `main.cpp`/config.h อย่ามั่ว 2 เวอร์ชันปนกัน
2. **U1=เข้า, U2=ออก** — ถ้าสลับหัวอ่านต้องแก้ `#define SS_IN/SS_OUT ...` ในโค้ดให้ตรง
3. **ECHO ต้องผ่าน R4/R3 เท่านั้น** ห้ามต่อตรงเข้า GPIO27 (5V ทำ ESP32 พัง)
4. **ESP32-CAM ไม่ต่อสายข้อมูล** — ต้องตั้ง MAC address ในโค้ดให้ตรงแทน
5. **GND ทุกก้อนต่อถึงกัน** (12V, 5V, ทุกโมดูล, กล้อง)
6. GPIO2 เป็น strapping pin (RFID ออก RST) — RC522 จ่ายไฟพร้อมบอร์ด ถ้าบูตค้างถอด-เสียบใหม่

> 📌 หมายเหตุถึงบอร์ด KiCad (`hardware/mainboard-min*`): บอร์ดพวกนั้นวางตาม
> **config.h** (เวอร์ชัน UART) ซึ่ง **pin ไม่ตรงกับ `.ino` นี้** ถ้าจะใช้บอร์ด KiCad
> กับเฟิร์มแวร์ ESP-NOW ต้องบอกผมแก้ pin map ของบอร์ดให้ตรง `.ino` ก่อน
