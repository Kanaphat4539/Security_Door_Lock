# คู่มือต่อสาย (EasyEDA) — Security Door Lock

รายการต่อสายสำหรับสکีมาติกใน EasyEDA ของคุณ — ตรงกับ `firmware/esp32-main/src/config.h`
ทุกขา ลากเส้นเชื่อมตามตารางได้เลย

**อุปกรณ์ในไฟล์:** ESP32 DevKit V1 (U3), RC522 ×2 (U1/U2), HC-SR04 (U5),
OLED SH1106 (U7), Relay module (U6), Buzzer (BZ1)+S8050 (Q1),
R1,R2=4.7k · R3=2k · R4,R5=1k
**เพิ่ม:** ESP32-CAM (UART) + step-down 12V→5V

> หมายเหตุ: ESP32 หลัก **ไม่มี WiFi** ในสถาปัตยกรรมนี้ — ทุกอย่างที่คุยเซิร์ฟเวอร์
> ส่งผ่าน **ESP32-CAM** ทาง UART

---

## 1. ไฟเลี้ยง (12V → step-down → 5V)

```
อะแดปเตอร์ 12V ──┬── step-down IN(12V) ── OUT(5V) ──► ราง 5V
                 │
                 └── 12V ──► Relay COM (สำหรับสวิตช์โซลินอยด์)

GND ของทุกก้อน (12V, step-down, ทุกโมดูล) ต่อถึงกันหมด = ราง GND
```

| ราง | มาจาก | จ่ายให้ |
|---|---|---|
| **5V** | step-down OUT | ESP32 **VIN**(ขา15) · HC-SR04 VCC · Relay **+** · Buzzer **+** · **ESP32-CAM 5V** |
| **3.3V** | ESP32 ขา **3V3**(ขา30) | RC522 U1.8 · RC522 U2.8 · OLED Vcc · ปลายบน R1,R2 |
| **GND** | ร่วมกันทั้งระบบ | ทุกโมดูล + ปลายล่าง R3 + Q1.E + 12V(−) |
| **12V** | อะแดปเตอร์ | step-down IN · Relay COM (ไปโซลินอยด์) |

> ⚠️ **GND ต้องต่อถึงกันหมด** ทั้งฝั่ง 12V และ 5V ไม่งั้นสัญญาณอ้างอิงไม่ตรง
> ⚠️ step-down ปรับ OUT ให้ได้ **5V** ก่อนต่อเข้าระบบ (วัดด้วยมัลติมิเตอร์)

## 5. HC-SR04 (U5) — ⚠️ ECHO เป็น 5V ต้องมีตัวแบ่งแรงดัน

| | |
|---|---|
| 1 VCC | ราง 5V |
| 4 GND | ราง GND |
| 2 TRIG | ESP32 **D33** (GPIO33) *(ต่อตรงได้)* |
| 3 ECHO | → **R4(1k)** → จุด A |
| จุด A | → ESP32 **D32** (GPIO32) **และ** → **R3(2k)** → GND |

```
ECHO ──[R4 1k]──┬── D32 (ESP32 GPIO32)
                │
              [R3 2k]
                │
               GND
```
(5V × 2k/(1k+2k) = 3.33V ← ปลอดภัยกับ ESP32)

## 6. Buzzer (BZ1) + Q1 (S8050) + R5

| | |
|---|---|
| ESP32 **D25** (GPIO25) | → **R5(1k)** → Q1.**B**(ขา2) |
| Q1.**C**(ขา3) | → BZ1.**−**(ขา2) |
| Q1.**E**(ขา1) | → ราง GND |
| BZ1.**+**(ขา1) | → ราง 5V |

```
D25 ──[R5 1k]── B┐
                 Q1 (S8050 NPN)
     BZ1(+)──5V  │
     BZ1(−)──C   │
             E───┴── GND
```

## 7. Relay module (U6)

| U6 | → |
|---|---|
| **S (IN)** | ESP32 **D26** (GPIO26) |
| **+** | ราง 5V |
| **−** | ราง GND |
| **COM** | 12V+ |
| **NO** | โซลินอยด์ ขั้ว + |
| **NC** | ไม่ต่อ |
| โซลินอยด์ ขั้ว − | 12V− (GND) |

> เมื่อ GPIO26 สั่ง HIGH → รีเลย์ดึง → COM ต่อ NO → 12V ไหลผ่านโซลินอยด์ → ปลดล็อก

## 8. ESP32-CAM (ต่อ UART กับ ESP32 หลัก)

ESP32-CAM ใช้ **UART0** (ขา U0T/U0R) คุยกับ ESP32 หลักที่ **UART2** (D16/D17)
**สาย TX ต้องไขว้เข้า RX เสมอ**

| ESP32 หลัก | ↔ | ESP32-CAM |
|---|---|---|
| **D17** (TX2, GPIO17) | → | **U0R** (RX) |
| **D16** (RX2, GPIO16) | ← | **U0T** (TX) |
| ราง 5V | → | **5V** |
| ราง GND | → | **GND** |

```
ESP32 หลัก D17(TX) ───────► CAM U0R(RX)
ESP32 หลัก D16(RX) ◄─────── CAM U0T(TX)
        5V ──────────────── CAM 5V
       GND ──────────────── CAM GND
```

> ⚠️ **ห้ามต่อ TX→TX / RX→RX** ต้องไขว้ (TX ตัวหนึ่งไป RX อีกตัว)
> กล้องกินกระแสตอนส่งภาพได้ถึง ~500mA → step-down ควรจ่ายได้ ≥1A

## ⚠️ จุดที่ต้องระวัง (สำคัญ)
1. **U1=เข้า, U2=ออก** — ถ้าสลับหัวอ่าน ต้องแก้ `config.h` ให้ตรง
2. **ECHO ต้องผ่าน R4/R3 เท่านั้น** ห้ามต่อตรงเข้า GPIO32 (5V ทำ ESP32 พัง)
3. **UART กล้องต้องไขว้ TX↔RX** ต่อผิดคุยกันไม่ได้
4. **GND ทุกก้อนต่อถึงกัน** (12V, 5V, ทุกโมดูล)
5. GPIO2/GPIO5 เป็น strapping pin — RC522 จ่ายไฟพร้อมบอร์ด ถ้าบูตค้างถอด-เสียบใหม่
6. step-down ตั้ง 5V และจ่ายได้ ≥1A (เผื่อกล้อง)
