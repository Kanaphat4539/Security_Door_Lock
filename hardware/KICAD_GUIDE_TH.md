# คู่มือทำ PCB เองใน KiCad — ทีละขั้น (บอร์ดหลัก Security Door Lock)

คู่มือนี้พาทำตั้งแต่เปิดโปรเจกต์ จนได้ไฟล์ส่งโรงงาน (Gerber) โดยเน้น
**การวางอุปกรณ์ + การลากสายทองแดง (routing)** ซึ่งเป็นส่วนที่ต้องทำมือ

ใช้ได้กับทั้งสองบอร์ด:
- `hardware/mainboard/` — **หน้าเดียว** (กัดเอง + jumper 24 เส้น)
- `hardware/mainboard-2layer/` — **สองชั้น** (สั่งโรงงาน เช่น JLCPCB)

> ไฟล์ที่ผมสร้างให้ **วางอุปกรณ์ + เดินลายมาแล้ว** คู่มือนี้จึงมี 2 แบบการใช้:
> **(A) แค่ตรวจ/แก้ของที่มีอยู่** (เร็ว) หรือ **(B) ทำใหม่เองจากศูนย์** (เรียนรู้)
> ทำตามหัวข้อได้ทั้งสองทาง

---

## สารบัญ
0. ศัพท์พื้นฐานที่ต้องรู้ก่อน
1. เปิดโปรเจกต์
2. อ่าน Schematic + รัน ERC
3. เปิด PCB Editor — รู้จักหน้าจอ

- ภาคผนวก A: ปุ่มลัดสำคัญ

- ภาคผนวก C: ปัญหาที่พบบ่อย

## 0. ศัพท์พื้นฐานที่ต้องรู้ก่อน

| คำ | ความหมาย |
|---|---|
| **Footprint** | รอยทองแดง/รูของอุปกรณ์จริงบนบอร์ด (เช่น รู 8 ขาของ RFID) |
| **Pad** | จุดทองแดงที่บัดกรีขาอุปกรณ์ |
| **Track / Trace** | เส้นทองแดงที่ลากเชื่อมระหว่าง pad |
| **Net** | "กลุ่มจุดที่ต้องต่อถึงกัน" เช่น net `+3V3` = ทุก pad ที่ต้องได้ไฟ 3.3V |
| **Ratsnest** | เส้นบางสีขาว/เหลือง บอกว่า pad ไหน "ยังต้องต่อ" ไปหา pad ไหน (ยังไม่ใช่ทองแดงจริง) |
| **Via** | รูชุบทองแดงเชื่อมลายชั้นบน (F.Cu) กับชั้นล่าง (B.Cu) |
| **Zone / Pour** | พื้นที่ทองแดงกว้าง (ใช้ทำ ground plane ของ GND) |
| **F.Cu / B.Cu** | ทองแดงด้านหน้า (Front) / ด้านหลัง (Back) |
| **DRC** | ตรวจกฎการผลิต (เส้นชนกัน/ชิดเกิน/ยังไม่ต่อ) |

**เป้าหมายของการ routing:** ทำให้ ratsnest (เส้นบางทุกเส้น) หายไปหมด
โดยแทนด้วย track ทองแดงจริง → เมื่อไม่เหลือ ratsnest = ต่อครบ

## 1. เปิดโปรเจกต์

1. เปิดโฟลเดอร์บอร์ดที่ต้องการ (เช่น `hardware/mainboard-2layer/`)
2. ดับเบิลคลิก **`mainboard.kicad_pro`** → เปิด KiCad Project Manager
3. จะเห็นไอคอน:
   - **Schematic Editor** (วงจร)
   - **PCB Editor** (แผ่นทองแดง)

> ครั้งแรกที่เปิด ถ้าถามเรื่อง library ให้กด OK/ใช้ค่าเริ่มต้น — ไฟล์อ้างอิง
> footprint มาตรฐานของ KiCad ที่ติดตั้งมาแล้ว

---

## 2. อ่าน Schematic + รัน ERC

เปิด **Schematic Editor**

- **เลื่อนดู:** กลิ้งเมาส์ = ซูม, กลางเมาส์กดค้าง = เลื่อน
- **ดูว่าอุปกรณ์ต่ออะไร:** เอาเมาส์ชี้เส้น/label ชื่อ net จะโชว์
- ป้ายชื่อ net (เช่น `RFID_ENTRY_SCK`, `+3V3`, `GND`) = "สายที่ชื่อเดียวกันคือ
  สายเส้นเดียวกัน" แม้จะไม่มีเส้นลากถึงกันบนจอ (ผมออกแบบด้วยวิธี global label)

**รัน ERC (ตรวจวงจร):**
1. เมนู **Inspect → Electrical Rules Checker**
2. กด **Run** → ควรได้ **0 errors** (ไฟล์นี้ผ่านแล้ว)

---

## 3. เปิด PCB Editor — รู้จักหน้าจอ

เปิด **PCB Editor**

- **แถบเลเยอร์ (ขวามือ):** คลิกเลือกว่าจะทำงานชั้นไหน
  - `F.Cu` (แดง) = ทองแดงหน้า
  - `B.Cu` (น้ำเงิน) = ทองแดงหลัง
  - `Edge.Cuts` (เหลือง) = เส้นขอบบอร์ด
  - `F.Silkscreen` = ตัวหนังสือ/ลายพิมพ์หน้า
- **หน่วย:** กด `Ctrl+U` สลับ mm/inch (ใช้ mm)
- **Grid:** เลือกที่แถบบน แนะนำ 0.5mm ตอนวางอุปกรณ์, 0.25mm ตอนเดินลายละเอียด

---

## 4. (เฉพาะถ้าจะทำใหม่จากศูนย์) Update PCB from Schematic

> ข้ามหัวข้อนี้ได้ถ้าใช้ไฟล์ที่ผมวาง+เดินลายมาแล้ว

1. ใน PCB Editor: เมนู **Tools → Update PCB from Schematic** (ปุ่มลัด `F8`)
2. กด **Update PCB** → อุปกรณ์ทั้งหมดจะถูกดึงเข้ามา กองรวมกันเป็นก้อน
3. คลิกวางก้อนนั้นลงกลางบอร์ด
4. จะเห็น **ratsnest** (เส้นบางโยงกันยั้วเยี้ย) = ยังไม่ได้เดินลาย

---

## 5. ตั้งค่า Design Rules

เมนู **File → Board Setup → Design Rules → Constraints** และ **Net Classes**

ค่าที่ผมตั้งให้ (เหมาะกับ JLCPCB 2 ชั้น):

| Net Class | Track width | Clearance | Via |
|---|---|---|---|
| Default | 0.3mm | 0.2mm | 0.6/0.3mm |
| Power (`+12V`,`+5V`,`+3V3`,`GND`) | 0.5mm | 0.2mm | 0.6/0.3mm |

> ถ้ากัดเอง (หน้าเดียว) ให้เพิ่ม clearance เป็น 0.4mm, track 0.4–0.6mm จะกัดง่ายกว่า

---

## 6. วางอุปกรณ์ (placement)

> ไฟล์ผมวางไว้ตามโซนใน `3Dpro/FrontBox/frontbox_pcb_spec.md` แล้ว
> หัวข้อนี้ไว้ปรับแต่ง/ทำเอง

**ปุ่มที่ใช้บ่อย (เอาเมาส์ชี้อุปกรณ์ก่อนกด):**

| ปุ่ม | ทำอะไร |
|---|---|
| `M` | **Move** — ยกอุปกรณ์ไปวาง (ตัด ratsnest ตามไปด้วย) |
| `R` | **Rotate** — หมุน 90° |
| `F` | **Flip** — พลิกไปอีกด้านของบอร์ด |
| `G` | **Drag** — ลากโดยคงสายที่ต่อไว้ |
| `E` | **Edit** — แก้ค่า/คุณสมบัติ |
| `Ctrl+Shift+M` | ระบุพิกัด X/Y แบบเป๊ะ |

**หลักการวางของบอร์ดนี้ (ตาม spec กล่อง):**
- Power-in (J1) + Relay-out (J8) → ขอบ **-Y** (ด้านล่าง)
- Programming/USB (J2) → ขอบ **+Y** (ด้านบน)
- Header เซ็นเซอร์บนฝา: RFID (J3/J4) กลางบน, OLED (J5) กลาง, HC-SR04 (J6) กลางล่าง
- **เสาอากาศ ESP32 (U1) หันออกขอบบอร์ด ห้ามมีทองแดงใต้เสาอากาศ** และห่างรีเลย์ ≥15mm

> วางอุปกรณ์ที่ต่อกันไว้ใกล้กัน จะเดินลายง่ายขึ้นมาก (เช่น C decoupling ชิดขา
> ไฟของ IC, ตัวแบ่งแรงดัน R6/R7 ชิด header HC-SR04)

## 7. ลากสายทองแดง (routing) — ละเอียด

นี่คือหัวใจ ทำทีละ net จนกว่า ratsnest จะหมด

### 7.1 เริ่มต้น
1. เลือกชั้นที่จะเดินก่อน: คลิก **`F.Cu`** ในแถบเลเยอร์ขวา
2. ตั้ง grid = 0.25mm (แถบบน) เพื่อความละเอียดตอนเข้าใกล้ขา IC

### 7.2 ลากเส้น 1 เส้น
1. กด **`X`** (Route Track) — หรือปุ่มรูปเส้นทแยงบนแถบขวา
2. **คลิกที่ pad ต้นทาง** (เช่น ขา SCK ของ ESP32) — สังเกตว่าถ้าเริ่มถูกจุด
   เส้น ratsnest ปลายทางจะไฮไลต์บอกว่าต้องไปไหน
3. เลื่อนเมาส์ไปทางปลายทาง คลิกเพื่อ "หักมุม" ระหว่างทาง
4. **ดับเบิลคลิกที่ pad ปลายทาง** เพื่อจบเส้น (ratsnest เส้นนั้นจะหายไป =
   ต่อสำเร็จ)
5. กด `Esc` เพื่อเลิกโหมดลาก

> เคล็ด: KiCad มี "push & shove" — ถ้าลากไปชนเส้นอื่น มันจะดันเส้นอื่นหลบให้
> อัตโนมัติ (เปิด/ปิดที่ Route → Interactive Router Settings → Highlight
> collisions / Shove)

### 7.3 เปลี่ยนชั้น + ใส่ via (สำคัญมากสำหรับ 2 ชั้น)
- **ระหว่างที่กำลังลากเส้นอยู่** กด **`V`** → KiCad จะหย่อน via ลงตรงนั้นแล้ว
  สลับไปเดินต่อบนอีกชั้น (F.Cu ↔ B.Cu) โดยอัตโนมัติ
- ใช้ตอนที่เส้นบนชั้นปัจจุบันตัน — มุดลงอีกชั้นแล้ววิ่งอ้อม แล้วค่อย `V` ขึ้นมาต่อ
- via ที่ผมวางให้มีอยู่แล้ว ~80 จุด; ถ้าทำเองใช้เท่าที่จำเป็น

### 7.4 แก้/ขยับเส้นที่ลากแล้ว
| ปุ่ม | ทำอะไร |
|---|---|
| `D` | **Drag** เส้น (ลากให้โค้ง/หลบ โดยคงการต่อ) |
| `M` | ย้ายทั้งเส้น |
| `Del` | ลบเส้น |
| `U` | เลือกทั้ง net (กดซ้ำขยายการเลือก) — ใช้ลบทั้งเส้นเร็วๆ |

### 7.5 ความกว้างเส้น
- เส้นสัญญาณทั่วไป 0.3mm พอ
- **เส้นไฟ (`+12V`,`+5V`,`+3V3`,`GND` ที่ไปรีเลย์/โซลินอยด์) ใช้ 0.5–0.8mm**
  เพราะกระแสสูง (โซลินอยด์ 12V กินกระแสมาก)
- เปลี่ยนความกว้าง: ระหว่างลากกด `W` (เพิ่ม) / `Shift+W` (ลด) หรือเลือกจาก
  dropdown แถบบน

### 7.6 ลำดับการเดินที่แนะนำ
1. **สายไฟก่อน** (`+12V` → `+5V` → `+3V3`) เส้นอ้วน เดินตอนบอร์ดยังว่าง
2. เส้นสัญญาณที่ออกจาก ESP32 (RFID, I2C, UART) — เดินออกจากขา IC ก่อนตอน
   รอบๆ ยังโล่ง
3. เส้นสั้นๆ ที่เหลือ
4. **GND ไว้ท้ายสุด** เพราะจะใช้ "pour" (หัวข้อ 8) ไม่ต้องลากทีละเส้น

> วิธีดูว่าเหลือกี่เส้น: มุมล่างมี **"Unrouted"** นับ ratsnest ที่เหลือ ทำจนเป็น 0
> (ยกเว้น GND ที่จะจัดการด้วย pour)

## 8. เท GND pour (ground plane)

แทนที่จะลาก GND ทีละเส้น เราเทเป็นพื้นทองแดงกว้าง

> ไฟล์ผมมี zone GND ทั้งสองชั้นให้แล้ว — แค่กด `B` เติม

**ถ้าทำเอง:**
1. เลือกชั้น `B.Cu` (ชั้นล่างเป็น ground plane หลัก)
2. กด **`Ctrl+Shift+Z`** (Add Filled Zone) หรือปุ่มรูปพื้นที่ทองแดงแถบขวา
3. คลิกวาดกรอบสี่เหลี่ยมคลุมทั้งบอร์ด (คลิกทีละมุม ปิดกรอบที่จุดเริ่ม)
4. หน้าต่างเด้งขึ้น: เลือก **net = `GND`**, layer = `B.Cu` → OK
5. ทำซ้ำสำหรับ `F.Cu` ถ้าต้องการ ground ทั้งสองด้าน
6. **กด `B`** = Fill All Zones → ทองแดงจะเติมเต็ม เว้นระยะรอบเส้น/pad อื่น
   อัตโนมัติ และ GND ทุกจุดจะเชื่อมเข้าพื้นนี้ (ratsnest GND หายหมด)

> ⚠️ ทุกครั้งที่แก้ลายเสร็จ ให้กด **`B`** เติม zone ใหม่ก่อนตรวจ/ส่งไฟล์เสมอ
> (kicad-cli/คำสั่งภายนอกไม่เติมให้)

---

## 9. รัน DRC (ตรวจก่อนส่ง)

1. เมนู **Inspect → Design Rules Checker**
2. ติ๊ก **Refill all zones before performing DRC**
3. กด **Run**
4. เป้าหมาย: **0 unconnected** และไม่มี error สีแดง
   - ดับเบิลคลิกที่รายการ error → จอจะซูมไปที่จุดนั้นให้แก้
   - warning `lib_footprint_mismatch` = ไม่เป็นไร (เกิดจาก footprint ที่ผมฝัง
     มาแบบย่อ) จะหายเมื่อกด Update from schematic ด้วย library เครื่องคุณ

---

## 10. Export Gerber ส่ง JLCPCB

> ผมมีสคริปต์สร้าง Gerber ให้แล้ว แต่ทำมือใน GUI ได้ดังนี้

1. **กด `B` เติม zone ก่อน** (สำคัญ!)
2. เมนู **File → Fabrication Outputs → Gerbers (.gbr)**
   - Layers ที่ต้องติ๊ก: `F.Cu`, `B.Cu`, `F.Paste`, `B.Paste`,
     `F.Silkscreen`, `B.Silkscreen`, `F.Mask`, `B.Mask`, `Edge.Cuts`
   - ติ๊ก **Use Protel filename extensions** ก็ได้ (JLCPCB รับทั้งสองแบบ)
   - กด **Plot**
3. กด **Generate Drill Files** → เลือก **Excellon**, ติ๊ก
   *PTH and NPTH in single file* (ตามที่ JLCPCB แนะนำ) → **Generate Drill File**
4. เอาไฟล์ `.gbr` + `.drl` ทั้งหมด **zip รวมกัน**
5. อัปโหลด zip ที่ jlcpcb.com → ระบบจะโชว์พรีวิวบอร์ด → ตรวจแล้วสั่งได้

**ตั้งค่า JLCPCB ที่แนะนำ:** Layers = 2, Thickness = 1.6mm, ที่เหลือค่าเริ่มต้น

## ภาคผนวก B: วิธีหา "อุปกรณ์นี้ต้องต่อไปไหน"

1. **ดู ratsnest:** เส้นบางจาก pad จะชี้ไปยัง pad ปลายทางที่ต้องต่อ
2. **ไฮไลต์ net:** เอาเมาส์ชี้ pad แล้วกด **`` ` ``** (backtick) หรือคลิกขวา →
   Highlight Net → ทุก pad/เส้นใน net เดียวกันจะสว่างขึ้น
3. **ดูชื่อ net:** ชี้ pad แล้วดูแถบล่าง จะบอกชื่อ net (เช่น `RFID_ENTRY_SCK`)
4. **เทียบกับตาราง** ใน `mainboard/README.md` (ตาราง pin map) ว่า net นั้นมาจาก
   GPIO ตัวไหนและต่อไป header ไหน
5. **เปิด Schematic คู่กัน:** คลิกอุปกรณ์ใน PCB แล้วกด `T` (หรือ cross-probe)
   จะกระโดดไปที่ตัวเดียวกันใน schematic เพื่อดูว่าต่ออะไร

## ภาคผนวก C: ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ratsnest ไม่หายทั้งที่ลากถึงแล้ว | ปลายเส้นไม่โดน pad จริง — กด `D` ลากปลายให้ทับกลาง pad |
| ลากเส้นไม่ได้ ขึ้นเตือนชนกัน | มีเส้น/pad อื่นขวาง — เปลี่ยนชั้นด้วย `V` แล้วอ้อม |
| DRC ฟ้อง "unconnected" ที่ GND | ยังไม่ได้กด `B` เติม zone |
| เส้นไฟร้อน/แรงตก | เพิ่มความกว้างเส้นไฟเป็น 0.8mm (`W` ระหว่างลาก) |
| footprint ไม่ตรงของจริงที่ซื้อมา | เช็ค datasheet โมดูล แล้วแก้ footprint/ลำดับขา ก่อนสั่งผลิต |
