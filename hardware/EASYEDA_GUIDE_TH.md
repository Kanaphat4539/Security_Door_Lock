# คู่มือทำ PCB ใน EasyEDA — ตั้งแต่เริ่มจนสั่งผลิต (Security Door Lock)

ไกด์เดียวจบ: วางอุปกรณ์ → ลากสาย → แปลงเป็น PCB → เดินลาย → สั่งผลิต
สำหรับ **บอร์ดหลัก (mainboard)** ที่ใช้ ESP32 DevKit เสียบ + โมดูลอยู่นอกบอร์ด

> อ้างอิงเฟิร์มแวร์จริง `firmware/esp32-main/src/esp_main/full-main_test.ino`
> (เวอร์ชัน **ESP-NOW** — กล้องคุยไร้สาย) · pin ตรงกับโค้ดนี้ทุกขา
> ภาพรวมสายดูที่ [WIRING_DIAGRAM.svg](WIRING_DIAGRAM.svg)

---

## ภาพรวม — บอร์ดนี้มีอะไร

**บนบอร์ด:** ESP32 DevKit (เสียบซ็อกเก็ต) + pin header ส่งไปโมดูลต่าง ๆ + ตัวต้านทาน/ทรานซิสเตอร์ไม่กี่ตัว
**นอกบอร์ด (ต่อผ่าน header/สาย):** RC522 ×2, OLED, HC-SR04, relay module, buzzer, ESP32-CAM (ไร้สาย)

```
                RC522#1   RC522#2
                   │         │
  OLED ──┐     ┌───┴─────────┴───┐     ┌── HC-SR04 (ECHO ผ่าน R6/R7)
         └─────┤  ESP32 DevKit   ├─────┘
  CAM(ไร้สาย)  │     V1 (เสียบ)   │
  5V/GND ······│                 ├───── Relay module (VCC/GND/IN) → โซลินอยด์ 12V
               └───────┬─────────┘
                    Buzzer (ผ่าน Q1)
  ไฟ: 12V → step-down → 5V → VIN ;  3.3V ← จากขา DevKit
```

## ขั้นที่ 1 — วางอุปกรณ์ในสกีมาติก

กด **Shift+F** หรือช่องค้นหา library (แถบซ้าย) แล้วหาแต่ละตัว วางลงหน้ากระดาษ:

| อุปกรณ์ | ค้นด้วย | จำนวน |
|---|---|---|
| ESP32 DevKit V1 | `DOIT ESP32 DEVKIT V1` | 1 (U3) |
| RC522 RFID module | `RC522` หรือ `Module RC522` | 2 (U1, U2) |
| OLED SH1106/SSD1306 | `SH1106` / `SSD1306 OLED` | 1 (U7) |
| HC-SR04 | `HC-SR04` / `ULTRASONIC` | 1 (U5) |
| Relay module | (ดู ⚠️ ด้านล่าง — ใช้ **header 3 ขา** ดีกว่า) | 1 |
| Buzzer | `BUZZER` | 1 (BZ1) |
| ทรานซิสเตอร์ NPN | `S8050` หรือ `MMBT2222A` | 1 (Q1) |
| ตัวต้านทาน | `R0805` | 5 (R4–R8) |

**ค่าตัวต้านทาน:** R4,R5 = **4.7k** · R6 = **1k** · R7 = **2k** · R8 = **1k**
(ดับเบิลคลิกที่ R → ใส่ค่าในช่อง Value)

> ⚠️ **Relay:** อย่าวาง symbol โมดูลรีเลย์เต็ม (6 ขา) เพราะเดี๋ยว footprint ไม่ตรง
> ให้ใช้ **ขั้ว JST-XH 3 ขา** (`B3B-XH-A`) แทน — ป้ายขา VCC/GND/IN
> (ตัวโมดูลรีเลย์จริงอยู่นอกบอร์ด NO/COM/NC + 12V จัดการที่โมดูล)

## ขั้นที่ 2 — ลากสายเชื่อม (สำคัญที่สุด)

ใช้เครื่องมือ **Wire** (ปุ่ม W) ลากเส้นเชื่อมขาตามตาราง
**pin ทั้งหมดตรงกับ `full-main_test.ino`**

### ไฟเลี้ยง
| ราง | จ่ายให้ |
|---|---|
| **5V** (จาก step-down / DevKit VIN ขา15) | HC-SR04 VCC · Relay + · Buzzer + · CAM 5V |
| **3.3V** (จาก DevKit ขา 3V3) | RC522 U1.8 · RC522 U2.8 · OLED Vcc · ปลายบน R4,R5 |
| **GND** (ร่วมกันหมด) | ทุกโมดูล · ปลายล่าง R7 · Q1.E · CAM GND |

### RC522 #1 = U1 (ทางเข้า)
| U1 | → ESP32 |
|---|---|
| SDA | D5 (GPIO5) |
| SCK | D18 (GPIO18) |
| MOSI | D23 (GPIO23) |
| MISO | D19 (GPIO19) |
| RST | D4 (GPIO4) |
| 3.3V / GND | ราง 3.3V / GND · IRQ = ไม่ต่อ |

### RC522 #2 = U2 (ทางออก)
| U2 | → ESP32 |
|---|---|
| SDA | TX2 (GPIO17) |
| SCK | D14 (GPIO14) |
| MOSI | D13 (GPIO13) |
| MISO | D35 (GPIO35) |
| RST | D2 (GPIO2) |
| 3.3V / GND | ราง 3.3V / GND · IRQ = ไม่ต่อ |

### OLED (I2C)
| OLED | → |
|---|---|
| SCL | D22 (GPIO22) |
| SDA | D21 (GPIO21) |
| Vcc / Gnd | 3.3V / GND |
| R4 (4.7k) | คร่อม SDA ↔ 3.3V |
| R5 (4.7k) | คร่อม SCL ↔ 3.3V |

### HC-SR04 — ⚠️ ECHO 5V ต้องมีตัวแบ่งแรงดัน
| | |
|---|---|
| VCC / GND | 5V / GND |
| TRIG | D26 (GPIO26) — ต่อตรง |
| ECHO | → R6(1k) → จุด A ; จุด A → D27(GPIO27) และ → R7(2k) → GND |

```
ECHO ─[R6 1k]─┬─ D27 (GPIO27)
              │
            [R7 2k]
              │
             GND
```

### Buzzer (ผ่าน Q1)
| | |
|---|---|
| D33 (GPIO33) | → R8(1k) → Q1.B |
| Q1.C | → Buzzer(−) |
| Q1.E | → GND |
| Buzzer(+) | → 5V |

### Relay (header 3 ขา)
| | → |
|---|---|
| IN | D25 (GPIO25) |
| VCC / GND | 5V / GND |

### ESP32-CAM = ไร้สาย (ESP-NOW)
**ไม่มีสายข้อมูล** ต่อแค่ **5V + GND** (header 2 ขา หรือจ่ายไฟแยก)
→ ในโค้ดต้องตั้ง **MAC address** ของ CAM ให้ตรง (ตัวแปร `camMacAddress[]`)

> ✅ ตรวจก่อนไปต่อ: ไม่มีสายค้าง (ทุกขาที่ใช้ต่อครบ) · GND ทุกก้อนถึงกัน

## ขั้นที่ 3 — แปลงเป็น PCB (หัวใจของการไม่ให้เลยกรอบ)

โมดูลจริงตัวใหญ่มาก ถ้าเอา footprint โมดูลมาวางบน PCB จะ **เลยกรอบ**
วิธีแก้: **เปลี่ยน footprint ของแต่ละโมดูลให้เป็น pin header**

**ทำทีละตัว** (RC522×2, OLED, HC-SR04, buzzer):
1. คลิกอุปกรณ์ในสกีมาติก
2. แถบขวา (Properties) → ช่อง **Footprint** → คลิกแก้
3. เปลี่ยนเป็น header ตามจำนวนขา:

ใช้ขั้วต่อ **JST-XH (2.5mm)** — มีล็อก กันเสียบผิด (ทั้งกลุ่มใช้ตัวนี้)
วิธีหา: แถบ **Library → LCSC** พิมพ์เลข LCSC ด้านล่าง วางแล้ว symbol+footprint มาเอง

| อุปกรณ์ | ขา | ขั้ว JST-XH (board) | LCSC |
|---|---|---|---|
| RC522 (U1, U2) | 8 | `B8B-XH-A` | **C157972** |
| OLED (U7) | 4 | `B4B-XH-A` | **C144395** |
| HC-SR04 (U5) | 4 | `B4B-XH-A` | C144395 |
| Relay | 3 | `B3B-XH-A` | **C144394** |
| Buzzer | 2 | `B2B-XH-A` | **C158012** |
| ไฟเข้า 5V/GND | 2 | `B2B-XH-A` | C158012 |
| ESP32-CAM (ไฟ) | 2 | `B2B-XH-A` | C158012 |
| ESP32 DevKit | (โมดูล) | `DOIT-ESP32-DEVKIT-V1` | — |

> **เก็บ symbol ไว้** เปลี่ยนแค่ footprint → บน PCB กลายเป็นขั้ว JST เล็ก
> ถ้าเจอ error "symbol pin ≠ footprint pad" = จำนวนขา symbol กับ footprint ไม่ตรง
> ให้เลือกขั้วที่จำนวนขาตรงกับ symbol
>
> ⚠️ **JST-XH = 2.5mm** (ไม่ใช่ 2.54) — ต้องมี **สายไฟ + ฝั่งสาย (housing + terminal)**
> ดูรายการในภาคผนวก A ส่วนโมดูล (RC522 ฯลฯ) ยังเป็นเข็ม 2.54 → ปลายสายฝั่งโมดูล
> ใช้ dupont ตัวเมีย 2.54 (คนละฝั่งกับ JST)

4. เมนูบน → **Convert to PCB** → จะได้หน้า PCB พร้อม footprint + เส้น ratsnest

## ขั้นที่ 4 — ตั้งขนาดบอร์ด + รูยึด

ยึดตามกล่อง FrontBox (`3Dpro/FrontBox`):

| รายการ | ค่า |
|---|---|
| ขนาดบอร์ด | **88 × 148 mm** (max 90×150) |
| มุมโค้ง | R3 |
| ความหนา | 1.6 mm |
| รูยึด 4 รู | (±41.75, ±71.75) จากกลาง · Ø2.3 (M2) |

**วิธีทำ:**
1. เลเยอร์ **BoardOutLine** → วาดสี่เหลี่ยม 88×148
2. PCB Tools → **Hole** วาง Ø2.3 ที่ 4 มุม (ห่างมุม 2.25mm) — (2.25,2.25)/(85.75,2.25)/(85.75,145.75)/(2.25,145.75)

⚠️ **DevKit เสียบสูง ~25-30mm** อาจเกินฝากล่องเดิม (18mm) — วัดจริงแล้วแจ้งฝั่งกล่อง

---

## ขั้นที่ 5 — วางตำแหน่ง + เดินลาย

1. **ลากอุปกรณ์** จัดตำแหน่งในกรอบ:
   - DevKit ตรงกลาง · ไฟเข้า/relay ที่ขอบล่าง · RC522 ด้านบน · OLED/HC-SR04 กลาง
   - ตัวแบ่งแรงดัน R6/R7 วางใกล้ header HC-SR04 · Q1/R8 ใกล้ header buzzer
2. **เดินลาย:** ปุ่ม **Route** (หรือ W บน PCB) คลิก pad → ลากไป pad ปลายทาง
   - ไฟ (5V/3V3/GND) ใช้เส้นกว้าง (0.4–0.6mm) · สัญญาณ 0.25–0.3mm
   - อยากได้ GND ทั้งแผ่น: Tools → **Copper Area** วาดคลุมทั้งบอร์ด net=GND
3. หรือใช้ **Auto Router** (Route → Auto Route) ให้เดินให้อัตโนมัติ แล้วค่อยแก้จุดที่ไม่สวย

---

## ขั้นที่ 6 — DRC (ตรวจก่อนสั่ง)

1. เมนู **Design → Check DRC** (หรือปุ่ม DRC)
2. แก้จน **ไม่มี error สีแดง** และไม่มีเส้นค้าง (unrouted)
3. error "pin ≠ pad" = footprint ไม่ตรง symbol (กลับไปขั้น 3)

---

## ขั้นที่ 7 — Export Gerber / สั่งผลิต

1. เมนู **Fabrication → PCB Order / Generate Gerber**
2. EasyEDA เชื่อม **JLCPCB** ตรง ๆ — กด order ได้เลย หรือดาวน์โหลด Gerber zip
3. ตั้งค่า: **Layers = 2, Thickness = 1.6mm**, ที่เหลือ default
4. ตรวจพรีวิว (ขอบบอร์ด + รู + ลาย) แล้วสั่ง

---

## ภาคผนวก C — ข้อควรระวัง
1. **ใช้ pin ของ `.ino` (ESP-NOW)** อย่าปนกับ config.h (คนละชุด)
2. **ECHO ต้องผ่าน R6/R7** ห้ามต่อตรงเข้า GPIO27 (5V ทำ ESP32 พัง)
3. **กล้องไร้สาย** — ต่อแค่ไฟ + ตั้ง MAC address ในโค้ด
4. **Relay ใช้ header 3 ขา** อย่าเอา footprint โมดูล 6 ขามาวาง
5. **GND ทุกก้อนถึงกัน** (12V, 5V, ทุกโมดูล, กล้อง)
6. **DevKit สูง** เช็คกับความสูงกล่องก่อนปิดฝา

## ภาคผนวก D — แก้ปัญหาที่เจอบ่อย
| อาการ | แก้ |
|---|---|
| PCB เลยกรอบ | ยังไม่เปลี่ยน footprint โมดูลเป็น header (ขั้น 3) |
| "symbol pin ≠ footprint pad" | จำนวนขา symbol ≠ footprint → เลือก header ขาตรงกัน |
| ratsnest ไม่หาย | ปลายเส้นไม่โดน pad — ลากปลายให้ทับกลาง pad |
| DRC ฟ้อง GND unrouted | ยังไม่เท Copper Area net=GND |
