# ตารางต่อสาย + สิ่งที่ต้องเพิ่ม — Security Door Lock (ฉบับ EasyEDA ที่คุณวาดอยู่)

อ่านคู่กับ `EASYEDA_FROM_ZERO_TH.md` (วิธีใช้โปรแกรม) และ `firmware/esp32-main/src/config.h` (ขาจริงในโค้ด)
> 🔌 **ตารางขาแบบรวมทุกอย่าง (รวม J1 / Q1+R8 / R6+R7 แล้ว) สำหรับใช้ตอนวางสัญลักษณ์: ดูที่ `PINOUT_TH.md`**
สัญลักษณ์ในไฟล์คุณ: **U3 = DOIT ESP32 DEVKIT V1** · **U1/U2 = Module RC522** · **U4 = OLED 1.3 128x64 I2C**
· **U5 = ULTRASONIC (4 ขา VCC/TRIG/ECHO/GND)** · **BZ1 = BUZZER** · **RELAY = SINGLE 6V-10A (ขา + , − , S(IN), NO, COM, NC)**

> หลักการ: **ไม่ต้องลากเส้นเชื่อมโมดูล** — ติด **NetLabel** ชื่อเดียวกันที่ขาที่ต้องต่อถึงกัน (กด `N`)
> รายชื่อเน็ตให้พิมพ์อยู่หัวข้อ 3 — พิมพ์ให้ตรงกันเป๊ะทุกตัวอักษร

## 1. ขาของ U3 (ESP32) ที่ต้องใช้

แถวซ้าย (บน→ล่าง): `EN · VP · VN · D34 · D35 · D32 · D33 · D25 · D26 · D27 · D14 · D12 · D13 · GND · VIN`
แถวขวา (บน→ล่าง): `D23 · D22 · TX0 · RX0 · D21 · D19 · D18 · D5 · TX2 · RX2 · D4 · D2 · D15 · GND · 3V3`

| ขา (ชื่อบนสัญลักษณ์) | GPIO | ใช้ทำอะไร | net |
|---|---|---|---|
| D5 | 5 | RFID ขาเข้า — SS | `RFID_ENTRY_SS` |
| D18 | 18 | RFID ขาเข้า — SCK | `RFID_ENTRY_SCK` |
| D19 | 19 | RFID ขาเข้า — MISO | `RFID_ENTRY_MISO` |
| D23 | 23 | RFID ขาเข้า — MOSI | `RFID_ENTRY_MOSI` |
| D27 | 27 | RFID ขาเข้า — RST | `RFID_ENTRY_RST` |
| D4 | 4 | RFID ขาออก — SS | `RFID_EXIT_SS` |
| D14 | 14 | RFID ขาออก — SCK | `RFID_EXIT_SCK` |
| **D35** | 35 | RFID ขาออก — MISO | `RFID_EXIT_MISO` |
| D13 | 13 | RFID ขาออก — MOSI | `RFID_EXIT_MOSI` |
| D2 | 2 | RFID ขาออก — RST | `RFID_EXIT_RST` |
| D33 | 33 | Ultrasonic TRIG | `US_TRIG` |
| D32 | 32 | Ultrasonic ECHO (ผ่านตัวแบ่งแรงดัน) | `US_ECHO_3V3` |
| D25 | 25 | สั่ง buzzer | `BUZZER_CTRL` |
| D26 | 26 | สั่ง relay | `RELAY_CTRL` |
| D21 | 21 | I2C SDA → OLED | `OLED_SDA` |
| D22 | 22 | I2C SCL → OLED | `OLED_SCL` |
| RX2 | 16 | สายไป ESP32-CAM (TX ของฝั่งนี้) | `CAM_TX2` |
| TX2 | 17 | สายไป ESP32-CAM (RX ของฝั่งนี้) | `CAM_RX2` |
| VIN | — | ไฟเข้า 5V จากตัวแปลง | `+5V` |
| 3V3 | — | จ่าย 3.3V ให้โมดูล | `+3V3` |
| GND (2 ขา) | — | กราวด์ | `GND` |
| EN · VP · VN · D34 · D12 · TX0 · RX0 · D15 | — | ไม่ใช้ | ติด No-Connect Flag |

⚠️ **D12 (GPIO12) ห้ามต่ออะไรเลย** — เป็น strapping pin ตั้งแรงดันแฟลชตอนบูต ถ้าถูกดึง HIGH บอร์ดจะบูตค้าง (เจอจริงตอนทดสอบ) → MISO ของ RC522 ตัวขาออกจึงย้ายมา `D35`
⚠️ **D35 / VP / VN / D34 เป็น input-only** — ใช้เป็นทางออกสัญญาณไม่ได้ (MISO เป็นอินพุตจึงใช้ได้)
⚠️ `D2` (GPIO2) ก็เป็น strapping pin เหมือนกัน — โปรเจกต์นี้ใช้เป็น RST ของ RC522 และทดสอบผ่านแล้ว ถ้าบอร์ดมีปัญหาตอนบูตให้ย้าย RST ไปขาว่างอื่น

## 2. ขาของโมดูลแต่ละตัว → ต่อกับอะไร

### U1 — Module RC522 (ฝาเข้า / VSPI)
| ขา | ชื่อ | ต่อกับ |
|---|---|---|
| 1 | SDA (=SS) | `RFID_ENTRY_SS` → U3.D5 |
| 2 | SCK | `RFID_ENTRY_SCK` → U3.D18 |
| 3 | MOSI | `RFID_ENTRY_MOSI` → U3.D23 |
| 4 | MISO | `RFID_ENTRY_MISO` → U3.D19 |
| 5 | IRQ | ไม่ใช้ → No-Connect Flag |
| 6 | GND | `GND` |
| 7 | RST | `RFID_ENTRY_RST` → U3.D27 |
| 8 | 3.3V | `+3V3` |

### U2 — Module RC522 (ฝาออก / HSPI)
| ขา | ชื่อ | ต่อกับ |
|---|---|---|
| 1 | SDA (=SS) | `RFID_EXIT_SS` → U3.D4 |
| 2 | SCK | `RFID_EXIT_SCK` → U3.D14 |
| 3 | MOSI | `RFID_EXIT_MOSI` → U3.D13 |
| 4 | MISO | `RFID_EXIT_MISO` → U3.D35 |
| 5 | IRQ | ไม่ใช้ → No-Connect Flag |
| 6 | GND | `GND` |
| 7 | RST | `RFID_EXIT_RST` → U3.D2 |
| 8 | 3.3V | `+3V3` |

### U5 — ULTRASONIC (4 ขา)
| ขา | ชื่อ | ต่อกับ |
|---|---|---|
| 1 | VCC | `+5V` (ต้อง 5V — อย่าต่อ 3V3) |
| 2 | TRIG | `US_TRIG` → U3.D33 |
| 3 | ECHO | `US_ECHO_5V` → R6 (ตัวแบ่งแรงดัน) — **ห้ามต่อตรงเข้า ESP32** |
| 4 | GND | `GND` |

### U4 — OLED 1.3" 128x64 I2C
| ขา | ชื่อ | ต่อกับ |
|---|---|---|
| 1 | VDD | `+3V3` |
| 2 | GND | `GND` |
| 3 | SCK | `OLED_SCL` → U3.D22 (+ R5 4.7k ขึ้น +3V3) |
| 4 | SDA | `OLED_SDA` → U3.D21 (+ R4 4.7k ขึ้น +3V3) |

### BZ1 — BUZZER (ต้องเพิ่ม Q1 + R8 — ดูหัวข้อ 4 ข้อ 1)
| ขา | ต่อกับ |
|---|---|
| 1 (+) | `+5V` (ขายาว = บวก) |
| 2 (−) | `BUZZ_LO` → ขา C ของ Q1 |

### RELAY — SINGLE 6V-10A RELAY MODULE
| ขา | ชื่อ | ต่อกับ |
|---|---|---|
| 1 | + | `+5V` |
| 2 | − | `GND` |
| 3 | S (IN) | `RELAY_CTRL` → U3.D26 |
| 4 | NC | ไม่ใช้ (ปล่อยว่าง) |
| 5 | COM | ไปขั้วต่อขั้วหนึ่งของโซลินอยด์/กลอนประตู |
| 6 | NO | ไปอีกขั้วของโหลด (ปิดวงจรเมื่อรีเลย์ทำงาน) |

### (ยังไม่มีในไฟล์) J_CAM — สายไป ESP32-CAM
| ขา | ต่อกับ |
|---|---|
| 1 | `+5V` |
| 2 | `GND` |
| 3 | `CAM_TX2` → U3.TX2 (ต่อกับ RX ของ CAM) |
| 4 | `CAM_RX2` → U3.RX2 (ต่อกับ TX ของ CAM) |

## 3. รายชื่อ Net ที่ต้องมี (คัดลอกไปพิมพ์เป็น NetLabel / NetFlag)

ไฟเลี้ยงใช้ **NetFlag** (มีมาให้ในพาเลต): `GND` · `+5V` · `+3V3` (วาง NetFlag VCC แล้วเปลี่ยนชื่อเป็น `+3V3`)
สัญญาณใช้ **NetLabel** (`N`) ตามนี้:

```
RFID_ENTRY_SS     RFID_ENTRY_SCK    RFID_ENTRY_MOSI   RFID_ENTRY_MISO   RFID_ENTRY_RST
RFID_EXIT_SS      RFID_EXIT_SCK     RFID_EXIT_MOSI    RFID_EXIT_MISO    RFID_EXIT_RST
US_TRIG           US_ECHO_5V        US_ECHO_3V3
BUZZER_CTRL       Q1_B              BUZZ_LO           RELAY_CTRL
OLED_SDA          OLED_SCL
CAM_TX2           CAM_RX2            (ถ้าทำสายไปกล้อง)
```

ถ้า EasyEDA ไม่ยอมรับชื่อที่มี `_` → เขียนติดกัน (`RFIDENTRYSS`) แล้ว **ใช้ชื่อเดียวกันทั้งบอร์ด**

## 4. ต้องเพิ่มอะไรใน Schematic (เรียงตามความสำคัญ)

**จำเป็น (ถ้าไม่เพิ่ม วงจรไม่ทำงาน/เสี่ยงพัง)**

1. **Q1 (NPN) + R8 1k — ชุดขับ buzzer**  ← ตอนนี้ BZ1 ต่อกับขา GPIO ตรง ๆ ซึ่ง **อันตราย**
   - เปลี่ยนเป็น: `U3.D25 → R8 → Q1.B` · `Q1.E → GND` · `Q1.C → BZ1.(−)` · `BZ1.(+) → +5V`
   - ไลบรารี EasyEDA: `S8050` (LCSC C181158) หรือ `2N3904(SOT-23)` ใน Common Library → Transistor
   - R8 1k: `1k 0805` → C17513
   - เหตุผลจากโค้ดจริง (`buzzer.cpp`): active buzzer กิน ~20–30 mA เกินที่ควรให้ GPIO จ่ายตรง ๆ
     (ถ้าไม่อยากบัดกรี SOT-23 ใช้ **buzzer module** ที่มีทรานซิสเตอร์ในตัวแทนก็ได้ แล้วต่อสัญญาณเข้า IN ของโมดูล)
   - ถ้าเป็น buzzer แบบ magnetic (มีขดลวด) ให้เพิ่มไดโอด 1N4148 คร่อมขั้ว buzzer (แคโทด→(+))

2. **R6 1k + R7 2k — ตัวแบ่งแรงดันที่ ECHO ของ ultrasonic**
   - `U5.ECHO → R6.1` · `R6.2 → R7.1 → U3.D32` · `R7.2 → GND`
   - ECHO ของ HY-SRF05/HC-SR04 จ่าย 5V แต่ GPIO32 รับได้ 3.3V → ต้องแบ่งก่อน
   - ค่าไลบรารี: `1k 0805` → C17513 · `2k 0805` → C17604

3. **ขั้วต่อไฟเข้า J1 (2 ขา: +5V / GND)** — ในไฟล์ยังไม่มีที่ป้อนไฟ
   - 3.3V ไม่ต้องป้อนจากนอกบอร์ด: ดึงจากขา `3V3` ของ DevKit (เลี้ยง RC522 ×2 + OLED ≈ 90 mA สบาย)
   - 5V ต้องจ่ายให้: relay coil (~70–90 mA) + ultrasonic (~15 mA) + buzzer (~30 mA) + ESP32-CAM (~250 mA ตอนส่งภาพ)
     → **ใช้ตัวแปลง 5V ≥ 1A** และถ้าต่อ USB ไว้ด้วยให้ระวังจ่ายไฟสองทาง

**แนะนำให้มี (ถูกมาก แต่ช่วยให้ไม่เจอปัญหาแปลก ๆ)**

4. **R4, R5 = 4.7k pull-up I2C** (`R4.1/R5.1 → +3V3`, อีกปลายเข้า SDA/SCL)
   - โมดูล OLED 1.3" ส่วนใหญ่มี pull-up มาให้แล้ว → ถ้าเช็คแล้วมี ไม่ต้องใส่
   - ใส่ไว้ไม่เสียหาย แต่ **อย่าใส่ซ้ำกับที่โมดูลมีอยู่แล้วหลายตัว** (bus จะดึงแรงเกิน)

5. **C 100–470 µF (อิเล็กโทรไลต์) คร่อม +5V/GND ใกล้ relay / ทางไปกล้อง** — กันบอร์ดรีเซ็ตตอนรีเลย์สับหรือกล้องส่งภาพ
   และ **C 100 nF (0805) ที่ขา VCC ของ U1/U2/U5/U4** ตัวละ 1 ตัว (กรองสัญญาณรบกวน SPI/I2C)

6. **J_CAM 1×4 (ไป ESP32-CAM)** ถ้าจะใช้กล้องจริง — โค้ดมี UART2 (`CAM_RX2/CAM_TX2`) เตรียมไว้แล้ว
   - ลำดับขา: `+5V · GND · CAM_TX2 · CAM_RX2` และต้อง **ไขว้กับฝั่งกล้อง** (TX ของที่นี่ → RX ของกล้อง)

7. **ขั้วต่อโหลด (2 ขา) สำหรับ COM/NO** — ไปต่อโซลินอยด์/กลอน; ใช้ screw terminal หรือ header 1×2 ก็ได้
   (NC ไม่ต้องต่อ ยกเว้นอยากให้ล็อกตอนไม่มีไฟ)

**ตรวจก่อนเดินลาย**

8. **polarity ของ relay**: `config.h` ตั้ง `kRelayActiveHigh = true` → โมดูลต้องเป็นแบบ **HIGH-trigger**
   ถ้าซื้อได้แบบ LOW-trigger (ที่ขายในไทยส่วนใหญ่เป็น LOW) ให้แก้เป็น `false` ในโค้ด **หรือ** เลือกโมดูลที่มีจัมเปอร์ HIGH/LOW
9. **รุ่นรีเลย์บนสัญลักษณ์เขียน 6V** — ถ้าคอยล์เป็น 6V จริง จ่าย 5V อาจสับไม่ติด ตรวจสเปกตอนซื้อ (ที่ใช้กับโปรเจกต์นี้ควรเป็น **5V**)
10. **จอ 1.3" = SH1106** (ไม่ใช่ SSD1306 ของ 0.96") → โค้ดหลัก `esp_main.ino` ใช้ `Adafruit_SH1106G` อยู่แล้ว
    ส่วน `display.cpp` เป็นเวอร์ชัน SSD1306 → **ใช้ให้ตรงกับจอจริง** ที่อยู่ I2C `0x3C` เหมือนกันทั้งคู่

## 5. ตรวจใน EasyEDA ให้ครบก่อน Convert to PCB

- [ ] วาง NetLabel ครบทุกบรรทัดในหัวข้อ 3 และไม่มีชื่อที่พิมพ์เพี้ยน (ตัวพิมพ์เล็ก/ใหญ่ถือว่าต่างกัน)
- [ ] ขาที่ไม่ใช้ติด No-Connect Flag: U1.5 · U2.5 · U3.EN, VP, VN, D34, D12, TX0, RX0, D15 · RELAY.4 (NC)
- [ ] `Ctrl+D` → Nets: ไม่มีเน็ตขึ้นแดง/เตือน และแต่ละเน็ตมี 2 ขาขึ้นไป
- [ ] ขา Q1 ถูกต้อง: R8 → **B** · GND → **E** · BUZZ_LO → **C** (ของจริง SOT-23 = 1 B / 2 E / 3 C)
- [ ] มี J1 (ไฟเข้า) และมี R6/R7 (ตัวแบ่ง ECHO) แล้ว
- [ ] ตรวจว่าไม่ได้ต่ออะไรกับ **D12** เลย
- [ ] ตรวจรุ่นจอ OLED ให้ตรงกับโค้ด (1.3" → SH1106)
- [ ] เตรียมของ PCB: ซ็อกเก็ต/header ให้โมดูลทุกตัว (RC522 ×2 = 1×8 · OLED = 1×4 · Ultrasonic = 1×4
      · Relay = 1×3 · Buzzer = 1×2 · CAM = 1×4 · ไฟเข้า = 1×2) + ซ็อกเก็ต 2×15 สำหรับ DevKit (ถ้าไม่บัดกรีตรง)
- [ ] ตั้งแต่ขั้น PCB: ห้ามเททองแดงใต้เสาอากาศ ESP32 (Solid Region → Type = `No Solid` → `Shift+B`)

## 6. ถ้ากัดแผ่นเอง (หน้าเดียว)

- บอร์ดนี้เป็นไฟล์ 2 ชั้นในไกด์ ถ้าจะกัดหน้าเดียวต้องเดิน jumper เพิ่ม ~14 เส้น
  (ดูตัวอย่างรายการ jumper + วิธีกัดที่ `hardware/mainboard-min-handmade/README_TH.md` และ `JUMPERS.md`)
- รูเจาะแนะนำ: ขา header/socket **1.0 mm** · via ของ jumper **0.7 mm** · รูยึด M2 **2.3 mm**
- ระวัง: relay ใช้โหลด 220V — ระยะห่างทองแดงฝั่ง COM/NO ต้องห่างจากส่วนสัญญาณให้มาก และอย่าลากสายไฟบ้านพาดบนบอร์ดสัญญาณ
