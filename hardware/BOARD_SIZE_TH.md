# ขนาดบอร์ด PCB — Security Door Lock (mainboard)

สเปกขนาดบอร์ดสำหรับวาดใน EasyEDA / ส่งฝั่งกล่อง (CAD)
อ้างอิงกล่อง **FrontBox** — `3Dpro/FrontBox/frontbox_pcb_spec.md`
จุดกำเนิด (0,0) = **กลางบอร์ด**

---

## 1. ขนาดบอร์ด

| รายการ | ค่า |
|---|---|
| **ขนาด (แนะนำ)** | **88 × 148 mm** (X กว้าง × Y สูง) |
| ใหญ่สุดที่ลงกล่องได้ | **90 × 150 mm** — ห้ามเกิน |
| มุมโค้ง | **R3 mm** (อย่างน้อย 3) |
| ความหนา | **1.6 mm** |

> ช่องว่างในกล่องคือ 92 × 152 mm (มีบล็อกน็อตมุม 10 mm) — เกิน 90×150 บอร์ดจะชนบล็อก

---

## 2. รูยึด 4 รู (M2)

| รายการ | ค่า |
|---|---|
| ตำแหน่ง (จากจุดกลาง) | **(±41.75, ±71.75) mm** |
| ระยะห่างรู | 83.5 (X) × 143.5 (Y) mm |
| ขนาดรูเจาะ | **Ø2.3 mm** (เผื่อน็อต M2) |
| เขตห้ามวางของ (keep-out) | วงแหวน **Ø8 mm** รอบรู |

**พิกัดวัดจากมุมล่างซ้าย** (บอร์ด 88×148 → รูห่างจากมุม 2.25 mm):

| รู | X (mm) | Y (mm) |
|---|---|---|
| ล่างซ้าย | 2.25 | 2.25 |
| ล่างขวา | 85.75 | 2.25 |
| บนขวา | 85.75 | 145.75 |
| บนซ้าย | 2.25 | 145.75 |

---

## 3. โซนวางขั้วต่อ (แนะนำตามกล่อง)

ทิศ: **+Y = ด้านบน** (ผนังฝั่ง RC522) · **−Y = ด้านล่าง** (ไฟเข้า/รีเลย์ออก/สายลอดพื้น)

| ขั้วต่อ | โซนบนบอร์ด |
|---|---|
| ไฟเข้า (step-down 5V / 12V) | ขอบ **−Y** |
| Relay output → โซลินอยด์ | ขอบ **−Y** (ฝั่ง X บวก) |
| RC522 (ไปฝา) | ใกล้ (0, +45) ด้านบน |
| OLED (ไปฝา) | ใกล้กลาง (0, −8) |
| HC-SR04 (ไปฝา) | ใกล้ (0, −52) ด้านล่าง |
| Buzzer | ใกล้ (34, 0) |

> RC522 / OLED / HC-SR04 อยู่บน **ฝากล่อง** เชื่อมด้วยสายสั้นเข้า header บนบอร์ด

---

## 4. วิธีวาดใน EasyEDA

1. ตั้งหน่วยเป็น **mm** (มุมขวาล่าง)
2. เลเยอร์ **BoardOutLine** → วาดสี่เหลี่ยม **88 × 148 mm**
3. ทำมุมโค้ง R3 (เลือกเส้น → ใส่ค่า radius) — ถ้าไม่จำเป็นจะปล่อยมุมฉากก็ได้
4. เมนู PCB Tools → **Hole** วาง 4 จุด Ø2.3 ตามพิกัดข้อ 2
5. เว้นรอบรู Ø8 mm ไม่ให้มีทองแดง/อุปกรณ์

---

## 5. ⚠️ ความสูง — คุณใช้ ESP32 DevKit เสียบ

กล่อง FrontBox เดิมเผื่อความสูงด้านบน **≤ 18 mm** (สำหรับชิป WROOM แบน)
แต่ **DevKit เสียบซ็อกเก็ต** สูงประมาณ **25–30 mm** (บอร์ด + header + ตัวเสียบ)

➜ **น่าจะสูงเกินฝากล่องเดิม** ต้องทำอย่างใดอย่างหนึ่ง:
- วัดความสูง DevKit ที่เสียบจริง เทียบความสูงในกล่อง
- ถ้าไม่พอ → เพิ่มความสูงกล่อง (แก้ CAD) หรือย้าย/วาง DevKit ให้เตี้ยลง

---

## 6. ✅ ข้อมูลที่ต้องส่งฝั่งกล่อง (CAD)
- ขนาดบอร์ด **88 × 148 mm**, มุม R3, หนา 1.6 mm
- รูยึด 4 จุด **(±41.75, ±71.75)**, Ø2.3 (M2)
- **ความสูงจริงของ DevKit ที่เสียบซ็อกเก็ตแล้ว** (สำคัญสุด — กำหนดความสูงกล่อง)
- ความสูงรีเลย์ (ถ้าใช้รีเลย์บนบอร์ด)
