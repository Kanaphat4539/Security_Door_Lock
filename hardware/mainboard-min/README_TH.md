# Mainboard-min — บอร์ดหลักแบบ minimal (อุปกรณ์หลักอย่างเดียว)

บอร์ด ESP32 hub เวอร์ชันย่อ **ไม่มีภาคจ่ายไฟบนบอร์ด** — รับ 5V และ 3.3V
จากตัวแปลงไฟภายนอกของคุณผ่าน `J1` ขนาดบอร์ดตาม `3Dpro/FrontBox`
(88 × 148 mm, รูยึด M2 4 รู)

## ⚡ เรื่องไฟที่ต้องรู้ก่อน (สำคัญ)
บอร์ดนี้ต้องการ **2 แรงดัน**:
- **3.3V** → ESP32 (U1), RC522 ×2, OLED
- **5V** → HY-SRF05, relay module, buzzer, ESP32-CAM

ป้อนที่ **J1** (3 ขา): `1=5V  2=3.3V  3=GND`
> ถ้าตัวแปลงไฟของคุณให้แค่ 5V ต้องหา 3.3V เพิ่ม (หรือบอกผมให้ใส่ LDO
> AMS1117 แปลง 5V→3.3V กลับเข้าไปบนบอร์ด)

## 📁 มี 2 ไฟล์ให้ใช้
| โฟลเดอร์ | คือ | ใช้ตอนไหน |
|---|---|---|
| `mainboard-min/` | **ไฟล์ฝึก** — วางอุปกรณ์ + เจาะรูให้แล้ว **ยังไม่ลากสาย** | เปิดแล้วลากสายเอง (มี ratsnest ขาว ๆ ชี้ทาง) |
| `mainboard-min-routed/` | **ไฟล์สำเร็จ** — เดินลาย 2 ชั้นครบแล้ว | ไว้ดูเทียบ/ใช้ถ้าไม่อยากลากเอง |

เปิด `mainboard.kicad_pro` ในแต่ละโฟลเดอร์

## 🔧 วิธีลากสาย (ย่อ — ฉบับเต็มที่ `hardware/KICAD_GUIDE_TH.md`)
1. เปิด `mainboard-min/mainboard.kicad_pro` → PCB Editor
2. จะเห็นอุปกรณ์วางไว้ + เส้นขาว (ratsnest) บอกว่าต้องต่ออะไรถึงอะไร
3. เลือกชั้น `F.Cu` → กด **`X`** คลิก pad ต้นทาง ลากไป pad ปลายทาง ดับเบิลคลิกจบ
4. ตัน? กด **`V`** ใส่ via มุดไป `B.Cu` แล้ววิ่งอ้อม
5. ไฟ (`+5V`,`+3V3`,`GND`) ใช้เส้นอ้วน 0.5mm; สัญญาณ 0.3mm พอ
6. GND กด **`B`** เทเป็น pour ไม่ต้องลากทีละเส้น
7. ครบแล้ว: Inspect → DRC ต้องได้ 0 unconnected

## ✅ เช็คลิสต์การต่อ (ลากให้ครบทุกแถว)

**ไฟเลี้ยง** (เส้นอ้วน / หรือใช้ pour)
| net | ต่อจุดพวกนี้ให้ถึงกัน |
|---|---|
| `GND` | ทุกจุด GND (ใช้ **copper pour** ง่ายสุด) |
| `+3V3` | J1.2 · U1.2 · C8.1 · C9.1 · R2.1 · R3.1 · J3.8 · J4.8 · J5.2 · R4.1 · R5.1 |
| `+5V` | J1.1 · J2.2 · J6.1 · J7.1 · J9.1 · J8.1 |

> (ยกเว้น GND ที่จัดการด้วย pour)

## หมายเหตุ
- pin map ตรงกับ `firmware/esp32-main/src/config.h` ทุกขา
- ECHO ของ HY-SRF05 เป็น 5V ผ่านตัวแบ่งแรงดัน R6(1k)/R7(2k) → 3.3V ก่อนเข้า GPIO32
- relay/buzzer เป็นโมดูล/มีทรานซิสเตอร์ขับ — GPIO ต่อเข้า input ได้เลย
